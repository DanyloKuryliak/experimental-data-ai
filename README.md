# Класифікація звернень у Databricks

Дослідження показує, як короткі описи категорій впливають на точність моделі Laya під час маршрутизації звернень підтримки. Дані підготовлено у Databricks за допомогою Spark. Laya перевірено без донавчання.

## Матеріали

- [Презентація PDF](presentation/support-ticket-routing.pdf)
- [Презентація PowerPoint](presentation/support-ticket-routing.pptx)
- [Ноутбук із кодом і збереженими результатами](support-ticket-routing.ipynb)

## Виконана робота

1. Перевірено та підготовлено дані звернень.
2. Побудовано просту базову модель для порівняння.
3. Перевірено Laya лише з назвами категорій.
4. Додано короткі описи категорій і повторено дослід на тих самих повідомленнях.
5. Перевірено результат на новій вибірці.
6. Додатково досліджено узагальнення за допомогою Spark ML.

## Основні результати

| Перевірка | Точність |
| --- | ---: |
| Проста модель | 21,8% |
| Laya лише з назвами категорій | 70,2% |
| Laya з короткими описами | 93,8% |
| Spark ML на нових підтемах | 62,5% |

Laya та Spark ML перевірялися на різних вибірках, тому їхні результати не слід порівнювати напряму.

## Виконання умов завдання

- Тема пов’язана з аналізом даних у Databricks.
- Презентація підготовлена на 15 хвилин.
- Ноутбук містить код і збережені результати виконання.
- Демонстрація охоплює підготовку даних, запуск Laya та аналіз помилок.
- Посилання на презентацію розміщено в README.
